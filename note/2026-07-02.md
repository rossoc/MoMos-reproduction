Indeed, the fold restriction is lifted at the largest admissible fold size.
In particular, when $k' = \lru{m / v}$ (or equivalently, $v = \lru{m / k'}$),
each fold can hold up to $m' = \lru{m / v}$ motifs, which matches the number of
blocks in its group. Since these $m'$ blocks can contain at most $m'$ distinct
motifs, each fold can be chosen to contain exactly the motifs used by its group.
Consequently, V-Fold MoMos recovers the full MoMos hypothesis space:
$\HH_{s,k,v,k'} = \HH_{s,k}$. This is the maximum $k'$ permitted by the
constraint $k' \le m'$; for any $k' < \lru{m / v}$, the inclusion
$\HH_{s,k,v,k'} \subsetneq \HH_{s,k}$ is strict and the compression is genuine.
