I am curious to compute the correlation between weights in the same block.
E.g. $x_1, x_2$, $x_2, x_3$, $x_3, x_4$, and $x_1, x_3$, ...

I want to investigate 
- how to compute the correlation
- how it changes throughout training. 
- how it changes with different block sizes
- how it changes with different block shapes

I am also curious to see the performance of MoMos2D on CNN: my guess is that
columns might work "better", as the structures that arise in MLPs are encoded in
the structure of the models' architecture for CNNs.

I also think that the way we select the motifs becomes increasingly relevant as
we diminish the capacity. Specifically, when we investigate the shape/structure
of the motifs, we might need to improve the algorithm to select the motifs.
