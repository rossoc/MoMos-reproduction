Can we constrain an MLP to behave like a decision tree?

1. Let the MLP have only one layer
2. Let the MLP have 2^d neurons, such that d is the size of each input
3. Let's apply the sign function as activation
4. Let's define the output of each neuron as o = (o_1, ..., o_(2^d))
5. Let's define the dictionary:
    ```
    - o_1 and o_2 and o_4 and o_(2^(d-1)) = l_1
    - o_1 and o_2 and o_4 and not o_(2^(d-1)) = l_2
    - o_1 and ... and not o_(2^(d-2)) and o_(2^(d - 1) + 1) = l_3
    - o_1 and ... and not o_(2^(d-2)) and not o_(2^(d - 1) + 1) = l_4
    ...
    - not o_1 and not o_3 and ... and not o_(2^d - 1) = l_d
    ```

Is this kind of MLP able to learn any binary decision tree where any kind of
linear transformation (R^d -> R^d) is applied to the input space?
Furthermore, is there a linear transformation (R^d -> R^d) such a binary
decition tree is able to learn the MLP?
I mean, with these constraint are the class of the MLPs and decision trees with
a linear function applied on the input equivalent to each other?
