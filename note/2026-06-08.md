I've been thinking about the hierarchical MoMos.
Defining the motifs $Z \in \mathbb{R}^{k \times s}$, such that $k$ is the number of motifs and $s$ is the block size;
and the mosaic $M \in [k]^{n/s}$, we can simplify a neural network with parameters $W$ as:

$$
W \approx \phi_Z(Z[M])
$$

Where $Z[M]$ corresponds to the \texttt{torch} operation of assigning the motifs $z_i \in Z = (z_1, ..., z_k)$ at the index indicated by $M = (i_0, ..., i_{n/s})$.
And $\phi_Z$ is a reshaping function that reassemble the weights $Z[M]$ so that they have the same shape as $W$, namely, it depends by the the motifs shape, and the output shape.
For the time being we consider that target neural network $W$ fixed, and so we do not parametrize over it, but it can be easily be extended to any neural network because we don't make assumptions on the actual shape of the neural network.
And so we can reduce the Kolmogorov complexity of the neural network with weights $W$:

$$
C(W) \leq& \, l(W) = n \cdot q \\
C(ZM) \leq& \, l(ZM) = ksq + \frac{n}{s} \lceil \log(k)\rceil + O(1)
$$

On the other hand, $Z[M]$ is equivalent to $Z^2[M']$, such that $M'=(i_0 \oplus i_1, ..., i_{n/s - 1} \oplus i_{n/s})$.
Where $\oplus$ is the concatenation operator: $\mathbb{R}^a \times \mathbb{R}^b \rightarrow \mathbb{R}^{a \times b}: (c_1, ..., c_a) \oplus (d_1, ..., d_b) = (c_1, ..., c_a, d_1, ..., d_b)$.
This yields to the same upper bound on the complexity of the original MoMos, and the same goes for it's approximation error:

$$
l(Z^2[M']) =  ksq + \frac{n}{2s} \lceil \log(k^2) \rceil \leq ksq + \frac{n}{\cancel{2}s} \cdot \cancel{2} \lceil \log(k) \rceil = l(Z[M])
$$

## Hierarchical Motif

At this point, we can increment the complexity of the motifs term ($Z$), maybe leaving the mosaic ($M$) unchanged.
Indeed, we can store $Z$ and a function $k' \rightarrow k^2$ to store all the possible couple.
This function can be stored as a matrix $\pi' \in \{0, 1\}^{k \times k}$, such that 

$$
c_{ij} = \begin{cases}
    1 & \text{ if } z_i \oplus z_j \in \phi^{-1}_{Z^2}(W)\\
    0 & \text{ otherwise }
\end{cases}
$$

Where $\phi^{-1}_{Z^2}$ reshapes $W$ into a vector $v \in \mathbb{R}^{\lceil n/s \rceil \times s}$, and $0s$ are added at the end of the vector so the reshaping is consistent; effectively strictly less than $s$ ($<s$) zeros are added.
This function encodes the couple of motifs with $C(\pi') \leq k^2$.
Furthermore, you can use $k'$ indexes to refer to a pair $z_i, z_j$

Sometimes a more compact encoding is possible: $\pi = [i \oplus j: z_i \oplus z_j \in \phi^{-1}_{Z^2}(W)]$; thus we have $|\pi| = k' \leq k^2$.
This encoding bounds $C(\pi) = C(\pi') + O(1) \leq k'\log(k^2) + O(1) = 2 k' \log(k) + O(1)$.

Summing up, we're adding some complexity on the motifs' side, leaving the mosaic at most unchanged.
Now let's consider the bounds on $k'$:

$$
k' \leq& \, k^2 \\
k' \leq& \lceil \frac{n}{2 \cdot s} \rceil
$$

The first inequality is simple: we need to reference at most $k^2$ motifs.
The second is true because in $\phi^{-1}_Z(W)$ there are at most $\lceil n/s \rceil$  unique blocks. In the same way,
in $\phi^{-1}_{Z^2}(W)$ there are at most $\lceil n / (2s) \rceil$ unique motifs.

Furthermore, if $\lceil \log(k') \rceil < \lceil 2 \log(k) \rceil$, we can describe the mosaic with fewer bits.

Finally, defining $\pi^* = \arg \min (l(\pi'), l(\pi))$ if 

$$
C(\pi^*) \leq l(\pi^*) \leq \frac{n}{s} \log(k) - \frac{n}{2s} \log(k') = \frac{n}{s} \log(k / \sqrt{k'}) = l(M) - l(M') \geq C(M) - C(M')
$$

then the description $Z, \pi^*, M'$ is equivalent and requires less bits than $Z, M$.

If the capacity is very low, then $k^2 < \frac{n}{2s}$, and it might be hard to find the right conditions to compress the motifs.
You can apply MoMos a second time every epoch, in this way you enforce the model to learn a representation that you can split in blocks.
Otherwise, the MoMos at the higher level can group more than two blocks.
Generalizing the previous hierarchical MoMos, given some motifs $Z \in \mathbb{R}^{k \times s}$, a mosaic $M \in [k]^{n/s}$, and a reshaping function $\phi_Z: \mathbb{R}^{n/s \times s} \rightarrow \mathbb{R}^{n}$, such that $W = \phi_Z(Z[M])$. Then, you can compute $\pi: k' \rightarrow k^{s'}$, and 
$\phi_{Z^{s'}}: \mathbb{R}^{n / (s \cdot s') \times (s \cdot s')} \rightarrow \mathbb{R}^n$ such that:

$$
W \approx \phi_Z(Z[M]) = \phi_{Z^{s'}}(Z^{s'}[\pi[M']])
$$

This result explains that, when you multiply by a factor of $m$ the size of the block, you need the number of motifs to the power of $m$ to achieve the same description class;
while the capacity fixes the number of motifs based on the number of total motifs, thus it fixes the size of the motifs in bits:
$$
C(Z) \leq ksq = \frac{n}{s} \cdot capacity \cdot s q = n \cdot capacity \cdot q
$$

Therefore, the number of bits that we use to describe $Z$ is directly proportional to $capacity$.
While the complexity of the mosaic is directly proportional to block size $s$.

## $\pi$

Before we showed how to increment the block size preserving the same description power of the target neural network.
Now I propose a $\pi: k' \rightarrow k^{s'}$ such that $k' \leq k^{s'}$, which allows to shrink the mosaic $M = \pi[M']$.

Notably, $\pi$ shall have a compact description because we only save bits as a difference between $l(M) - l(M')$.
Noting that when $|Z^{s'}| = |Z|^{s'} \geq n / (s \cdot s')$, we can remove some motifs from $Z^{s'}$ without losing the description power relatively to the target network $W$ (where $|W| = n$).
In any case, we never need to store the full motifs $Z^{s'} = \prod_{i \in [s']} Z$.
Instead, we can compute a new set of motifs $\zeta$ on the motifs, such that $|\zeta| \leq n / (s \cdot s')$ for $\zeta \subseteq Z^{s'}$.

I have thought that such set could be defined as $\zeta = \prod_{i \in [s']} \zeta_i$, for $\zeta_i \subseteq Z$.
Thus, for each $\zeta_i$ we can store the list of indexes of $Z$ that are contained in $\zeta_i$: $\iota_i = \{j: z_j \in \zeta_i \, , z_j \in Z\}$.
Effectively $\zeta$ is used only now to explain the reasoning, but $\pi: k' \rightarrow k^{s'}$ can be computed storing only $\iota = [\iota_1, ..., \iota_{s'}]$.
Noting that $l(\iota) = \prod_{i \in [s']} |\iota_i| \log_2(k) = \log_2(k) \cdot \sum_{i \in [s']} |\iota_i|$ and $k' = \prod_{i \in [s']} |\iota_i|$, yielding
$l(M') = n / (s \cdot s') \log_2 k'$.

Defining $\pi: k' \rightarrow k^{s'}$ as follow:

$$
\pi(a) := \bigoplus_{i = 1}^{s'} \iota_i \left[ \left\lfloor \frac{a \mod \prod_{j = i}^{i} \iota_j}{\prod_{j = 1}^{i - 1} \iota_j} \right\rfloor \right]
$$

Which corresponds to slicing the index into $s'$ slices, and reading $i$-th slice as an index of $\iota_i$.

This representation is compact, because we use independent sets $Z_i$. Maybe we can figure out a way to index the motifs in $Z^{s'}$ that is more flexible, but the first experiments will use this simplification.

This approximation of the target neural network have complexity bounded by:

$$
C(Z, \iota, M') = ksq + \log_2k  \cdot \sum_{i \in [s']} |\iota_i| + \frac{n}{s s'} \log_2 k'
$$
