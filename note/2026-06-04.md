We need to transition the training behavior from a standard MoMos setup to a 
"doubled" hierarchical setup halfway through the training process.
Basically for some part of the training a momos callback is to be applied.
For the final part of the training a different momos callback should be applied.
In particular the second half should apply the first momos2d and a second
momos2d.

Can new implement it as a new method, and so with its own config called momos_hierarchy

Proposed Implementation Plan
1. Configuration Updates
We need to introduce new parameters in the Hydra configuration to control the hierarchy logic.
- epochs: the number of epochs where only the first momos is applied
- hierarchy_epochs: the number of epochs where both first and second momos are applied.
- hierarchy_params: Define the specific rows and cols, capacity, k for the second phase (e.g., 2, 2).
2. Model Modification (model/lit_module.py)
- Hierarchical Logic: Implement the "twice in each epoch" logic. Where "twice" means two sequential quantization steps, we need to define the
internal loop that executes these two operations during the hierarchical phase.
